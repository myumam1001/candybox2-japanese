回復ポーション / 回復ポーションの調合は実に簡単だ。必要なのはキャンディだけ。クエスト中に使うと、体力を100ポイント回復してくれる。 / 手順 : - 大釜にキャンディを100個入れる - 数秒間かき混ぜる - 瓶に詰める / もちろん、他のポーションと同様に量を増やすこともできる。例えば、100個の代わりに300個のキャンディを使えば、3つの回復ポーションが手に入る。

カメポーション / カメポーションは回復ポーションより少し調合が難しい。キャンディとロリポップの両方が必要だ。 / クエスト中にこのポーションを飲むと、カメに変身する。動きは遅くなるが、敵の攻撃に対する耐性が上がる。 / 手順 : - 大釜にキャンディを50個入れる - 大釜にロリポップを500個追加する - 10秒前後かき混ぜる - かき混ぜるのをやめる - キャンディを50個追加する - 再び数秒かき混ぜる - 瓶に詰める / そして、絶対に忘れてはいけない最も重要なこと : 一度カメになったら、絶対に「ひっくり返らない」ことだ。起き上がれなくなってしまうからね。

反重力ポーション / 有名な魔法使いアイザックによって発明されたこのポーションを使えば、クエストでずっと高くジャンプできるようになる。 / ただし、調合は少しばかり厄介だ。手順に正確に従うよう気をつけてほしい。 / 手順 : - 大釜にロリポップを1万個入れる - 泡立つまでかき混ぜる - かき混ぜるのをやめる - 大釜にキャンディを1万個追加する - 泡立つ液体の色が変わるまで再びかき混ぜる
jp.cauldron.page5
- 瓶に詰める / 大釜の中身を均一に加熱できるように、大釜をアップグレードすることを強くお勧めする。そうしなければ、複数の反重力ポーションを一度に調合するのはかなり難しくなるだろう。

バーサークポーション / このポーションは非常に危険だ。飲むと怒りに狂い、恐ろしいスピードで敵を攻撃できるようになるが、代わりに魔法が一切使えなくなる。 / リスクを冒してでも強大な敵を倒したい時だけ使うように。 / 調合の過程も同じくらい危険で、休む暇は一切ない。集中して挑むこと。 / 手順 : - 大釜にキャンディを2万個、ロリポップを2万個入れる - 約10秒かき混ぜる

- さらにキャンディを1万個、ロリポップを1万個追加する - 約10秒かき混ぜる - さらにキャンディを1万個、ロリポップを1万個追加する - 約10秒かき混ぜる - 瓶に詰める / バーサークポーションの調合に失敗すると、大釜が爆発する恐れがあると言われている。くれぐれも慎重に。

Pポーション / Pポーションは謎に包まれている。その存在は誰もが知っているが、効果や調合方法は誰も知らないようだ。 / 正確に言えば、調合方法が全く分からないというのは完全に事実というわけではない。実際に調合に成功した人々の話によれば、大釜に様々な量のキャンディとロリポップを入れ、様々な時間かき混ぜるなど、ただランダムにやっていただけだという... / Pポーションのレシピは一つではなく、無数に存在し、そのどれもがかなり複雑なようだ。確実に言えるのは、どれも大量のキャンディとロリポップを必要とするということだけだ...
jp.cauldron.page9
- Pポーションを飲む際には奇妙な法則がある。これらは経験則から定義されたものだが、かなり的を射ているようだ。 / - Pポーションを使えば使うほど、より奇妙な効果が現れるようだ。 / - 体力が残り少ない時こそ、Pポーションを飲むべきだろう。 / - 動物がPポーションを飲むと、非常に悪い反応を示すようだ。

Xポーション / Xポーションは伝説だ。これを調合して飲んだ者は、誰も足を踏み入れたことのない場所へ旅立つことができると言われている。 / このポーションが単なる伝説に過ぎないのかは分からないが、私が知っているすべてをこの本に記しておこう。 / Xポーションは多くの古い伝説や錬金術の書物に登場する。調合の役に立つかもしれない情報をまとめておいた。健闘を祈る！ / - Xポーションを調合するには5つの手順が必要だと言われている。 / - ある1つの手順を除いて、ロリポップは一切必要ないと言われている。 / - 他のポーションとは異なり、Xポーションを一度に複数調合することはできないと言われている。
